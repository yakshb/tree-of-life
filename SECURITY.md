# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, exposed secret,
or abuse path.

Contact [@yakshb](https://github.com/yakshb) through the private contact method
listed on the maintainer's GitHub profile. Include the affected route or
component, reproduction steps, likely impact, and any suggested mitigation.

Security fixes target the current `main` branch and public deployment. Never put
a Groq API key, `.env.local`, private dataset, or user content in an issue, pull
request, screenshot, or CI log.
