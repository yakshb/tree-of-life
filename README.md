## Introduction

The AI-Interactive Tree of Life Explorer is an innovative educational tool designed to visualize and explore the evolutionary relationships between different life forms. This project aims to make complex biological concepts more accessible and engaging through interactive visualization and AI-assisted learning.

By combining modern web technologies with data visualization and artificial intelligence, this tool offers a unique, hands-on approach to understanding the tree of life. Users can navigate through various branches, explore different species, and receive AI-generated information about selected life forms.

## Features

- Interactive visualization of the tree of life
- AI-assisted exploration and information retrieval
- Dynamic node expansion and collapsing
- Zoomable and pannable interface
- Exploration path tracking
- Responsive design for various screen sizes

## Frameworks 

- [Next.js](https://nextjs.org/) - React framework for server-side rendering and routing
- [React](https://reactjs.org/) - JavaScript library for building user interfaces
- [TypeScript](https://www.typescriptlang.org/) - Typed superset of JavaScript
- [react-d3-tree](https://github.com/bkrem/react-d3-tree) - React component to create interactive D3 trees
- [Framer Motion](https://www.framer.com/motion/) - Animation library for React
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework

## Getting Started

To get a local copy up and running, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/tree-of-life.git
   ```

2. Navigate to the project directory:
   ```
   cd tree-of-life
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Run the development server:
   ```
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.


## Key Components

- `VisualTreeOfLife`: The main component that orchestrates the tree visualization and user interactions.
- `AIAssistant`: Handles user queries and provides AI-generated responses.
- `InfoPanel`: Displays detailed information about selected nodes.
- `ExplorationPath`: Shows the user's navigation history through the tree.
- `CustomNodeRenderer`: Defines the appearance and behavior of individual tree nodes.

## AI Integration

The AI component of this project is designed to provide intelligent responses to user queries about life forms. While the current implementation uses placeholder responses, future versions aim to integrate with advanced language models like GPT to offer more sophisticated and accurate information.
